# CNT3004 - Computer Network Concepts

## Assignment/Lab 1 - Networking Fundamentals & Infrastructure

The assignment re-introduced me to browser Wireshark, browser Developer tools, and introduced me to using Command Prompt to investigate ping and other networking details about my home computer. I learned how to identify a computer's hostname, active network adapter, IPv4 address, MAC/physical address, and default gateway, how to use traceroute and what information it reveals, as well as how to ping web addresses.

One challenge I faced was not too significant, but it was getting used to the UI of Command Prompt (or lack thereof). I had very little experience using Command Prompt prior to this, however I have been exposed to barebones UIs before in a professional setting when configuring device BIOS-settings. After running several commands, I became more familiar with Command Prompt. The assignment helped me better understand both Command Prompt and Wireshark.

## Assignment/Lab 2 - Network Addressing, Protocols & Routing

This assignment focused more on Wireshark (while still using Command Prompt) as well as concepts such as HTTP GET requests, TCP, and UDP. Specifically, I learned how to use Wireshark to filter DNS, packets of specific IP Addresses, and how to analyze packet information to find values such as DNS Query, Source Port, and Destination Port. Additionally, TTL was also part of the assignment.

One challenge I faced initially was entering certain Wireshark commands incorrectly. I believe "ip.addr == 8.8.8.8 && dns" gave me issues, whether I forgot an ampersand (&) or an equals. Regardless, I eventually figured out the proper formatting convention for filtering through packets in Wireshark. Overall, the assignment helped me better understand the differences between UDP and TCP, as well as how to better analyze packet information in Wireshark.

## Assignment/Lab 3 - Network Media and Wireless Networking

This assignment focused on network media, bandwidth and throughput, wireless networking, and Wi-Fi frame analysis using Wireshark. Specifically, I learned about the differences between coaxial, UTP, and fiber-optic cables, as well as how bandwidth and throughput affect network performance. The assignment also covered multiplexing techniques such as TDM, FDM, and WDM, along with wireless networking concepts such as signal propagation, frequency bands, and Wi-Fi security. Additionally, I learned how to use Wireshark to filter and identify different types of 802.11 frames, including management, control, and data frames. I also analyzed beacon frames to identify information such as the SSID and beacon interval.

Getting the I/O Graph is Wireshark to display properly was challenging. Initially vertical scale was incorrect, I believe because I initially selected the wrong set of packets. Eventually I got the graph to display values that were more in line with what the assignment was asking for. Overall, this assignment gave me further insight on new ways to sort frames, as well as how to obtain some measurements of network performance.

## Assignment/Lab 4 - Virtualization, Cloud Computing, Subnets, and VLANs

This assignment re-introduced me to Oracle VirtualBox, and introduced me to subnets and VLANs. I have used virtual machines in the past, however I was not familiar with the networking aspect of it. The assignment also further familiarized me with Linux. Additionally, Wireshark's packet sniffer was part of the assignment.

I believe my biggest challenge was setting up the Linux virtual machine, primarily because I am most familiar with Windows operating systems. Overall, the assignment further-familiarized me with windows, and also taught me how to use the Wireshark packet snigger to examine packets.

## Assignment/Lab 5 & 6 - Network Security, Performance, Recovery, and WANs

This assignment focused on TCP Fault Recovery, and how to capture and analyze faults using Wireshark. The assignment involved analyzing our own traffic, as well as loading a file of other network traffic. In regards to analyzing TCP, the assignment familiarized me with Duplicate ACKs, Retransmission, and Fast retransmission.

My biggest challenge was getting the correct values for the Duplicate ACKs, Retransmission, and Fast retransmission, as I had some difficulty figuring out how to locate Duplicate ACKs and ended up entering the values in the incorrect order the first time. The assignment also had us calculate retransmission rate, as well as cost of loss.

## Overall Reflection

This course has informed me about important aspects of networking, as well as familiarized me with important applications and programs used in networking. For example, I gained a better understanding of networking protocols and how different components of a network communicate with one another. Learning about protocols such as TCP, UDP, HTTP, and DNS helped me better understand the processes that occur behind  network communications. Having used Wireshark in a previous course, CNT3004 went into much more depth regarding how to use Wireshark, and how to analyze information about a networking using Wireshark. I learned about important networking windows commands, which have been useful in other courses. My networking skills and knowledge have significantly improved and grown from taking this course, and I believe that all of the information learned will be relevant for my future career ambitions.
