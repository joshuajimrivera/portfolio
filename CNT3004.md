## Assignment/Lab 2 - Network Addressing, Protocols & Routing

This assignment focused more on Wireshark (while still using Command Prompt) as well as concepts such as HTTP GET requests, TCP, and UDP. Specifically, I learned how to use Wireshark to filter DNS, packets of specific IP Addresses, and how to analyze packet information to find values such as DNS Query, Source Port, and Destination Port. One challenge I faced initially was entering certain Wireshark commands incorrectly. I believe "ip.addr == 8.8.8.8 && dns" gave me issues, whether I forgot an ampersand (&) or an equals. Regardless, I eventually figured out the proper formatting convention for filtering through packets in Wireshark. Overall, the assignment helped me better understand the differences between UDP and TCP, as well as how to better analyze packet information in Wireshark.
